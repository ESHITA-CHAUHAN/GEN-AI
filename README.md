# Rewrite Studio

A responsive writing assistant for improving clarity and grammar while preserving the writer's meaning. It returns a primary rewrite, an optional second style, source claims, and a clearly labeled short interpretation.

Current Netlify deployment: https://gen-ai-rewrite-studio-doom.netlify.app/

## Features

- Clear, professional, and friendly rewrite styles
- Optional second rewrite for comparison
- Copy buttons for the original and generated versions
- Original source sentences and generated interpretation shown separately
- Responsive layout, character limit, keyboard shortcut, and visible request errors
- Model calls run through Netlify AI Gateway in server-side Functions; no personal OpenAI key is needed on Netlify
- No demo output that pretends to be AI: the app reports when Netlify AI Gateway is unavailable
- Basic per-instance request throttling and a 48-second provider timeout

## Run locally

Requires Node.js 18.14 or newer and npm.

1. Install the development tools:

       npm install

2. Make sure this directory is linked to your Netlify project and you are signed in to the team with Netlify AI features enabled.
3. Start the Netlify local environment:

       npm run dev

4. Open http://localhost:8888.

No personal OpenAI key is needed. The local page uses this project's live Netlify Function for rewrites, and the function uses Netlify AI Gateway. Successful model calls use the team's Netlify credits.

## Deploy to Netlify

The project is configured for a static publish folder and two Netlify Functions. Netlify's functions directory is outside the publish folder so backend source is not shipped as public site files.

1. Install dependencies with `npm install`.
2. Sign in to Netlify using the Netlify CLI, then link the existing project from this directory.
3. Enable Netlify AI features for the team if they are turned off.
4. Deploy the production site. Netlify AI Gateway supplies the server-side provider configuration automatically.

Do not put provider keys in `netlify.toml`, `public/`, or any `VITE_`/client-visible variable. Netlify AI Gateway supplies its key only to server-side functions.

## Environment variables

| Name | Required | Default | Purpose |
| --- | --- | --- | --- |
| `OPENAI_API_KEY` | No on Netlify | Netlify AI Gateway | Optional key for a non-Netlify provider |
| `OPENAI_MODEL` | No | `gpt-4o-mini` | Model name accepted by the provider |
| `OPENAI_BASE_URL` | No on Netlify | Netlify AI Gateway | Optional base URL for a non-Netlify provider |

The rewrite endpoint accepts JSON with `text`, `style`, and `both`. It rejects empty text and drafts longer than 5,000 characters. The statements panel is built from the original input sentences; the interpretation is generated by the model. Requests are sent to the configured provider and are not stored by this app. Provider retention and privacy practices still apply.

## Project files

- `public/` — browser interface and assets
- `netlify/functions/rewrite.mjs` — validated rewrite endpoint
- `netlify/functions/status.mjs` — reports whether Netlify AI Gateway is available, without exposing credentials
- `netlify/functions/ai-config.mjs` — reads Netlify-injected AI Gateway settings or optional provider settings
- `netlify.toml` — build, functions, development, and security-header configuration
- `scripts/check-build.mjs` — checks the required deployment files
- `group3_source_code.zip` — refreshed source bundle
- `report.docx`, `presentation.pptx`, `presentation-outline.md` — class project materials
